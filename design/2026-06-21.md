# 2026-06-21 — Correction-to-action handoff

## Фокус дня

Состояние после исправления memory receipt на Day 2-7: пользователь поправил, что SiaMentor запомнил из прошлого check-in, и сразу получает следующий маленький шаг из книги.

## Проблема

Если memory gate заканчивается только сообщением "исправлено", продукт выглядит как настройка профиля, а не companion для привычки. После коррекции нужно быстро вернуть пользователя в цепочку:

книга -> выполненное действие -> проверенная память -> следующее действие -> привычка.

Иначе возрастает риск, что пользователь исправил данные, но не сделал daily action, а paywall после трех действий теряет доказательную базу.

## Дизайн-решение

После нажатия `исправить` показываем compact correction sheet поверх habit surface:

1. Поле "Что было иначе?" с подсказками только из habit-domain: триггер, действие, помеха.
2. Кнопка `Обновить следующий шаг`.
3. После сохранения sheet закрывается в состояние `memory_corrected_next_action`.
4. Today's action пересобирается на основе corrected fields и явно показывает, что изменилось.

Главное правило: correction не должна быть отдельной задачей. Она должна завершаться новым action card на 5-10 минут.

## Ключевые состояния

- `memory_receipt_needs_review`: строка "Помню: вчера ты читал после завтрака, но отвлек телефон" и действия `верно / исправить / забыть`.
- `memory_correction_sheet`: пользователь исправляет один или два bounded поля, без свободного профилирования личности.
- `memory_corrected_next_action`: экран возвращается к today's action с receipt "Обновил память: триггер теперь после кофе".
- `action_completed_after_correction`: check-in привязан к corrected memory через `source_checkin_id`.
- `paywall_ready_after_3_actions`: proof state считает только completed actions, не сами corrections.

## UX-copy

Receipt:

> Помню из прошлого раза: после завтрака было удобно, но мешал телефон.

Correction sheet:

> Что было иначе?

Placeholder:

> Например: не после завтрака, а после кофе; мешали не уведомления, а спешка.

Success:

> Обновил. Тогда сегодняшний шаг лучше сделать после кофе.

Today's action:

> Открой книгу на 5 минут после кофе. Отметь одну мысль, которую можно проверить сегодня.

Check-in:

> Сделал? Что помогло или помешало?

## Открытые вопросы

- Должна ли correction требовать отдельного confidence score или достаточно наследовать confidence от нового check-in?
- Нужно ли показывать "забыть" рядом с corrected next action или только в исходном memory receipt?
- Как ограничить свободный текст так, чтобы correction оставалась полезной, но не превращалась в broad personal profile?
