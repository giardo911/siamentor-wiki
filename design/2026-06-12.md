# 2026-06-12 — Paywall proof после третьего действия

## Фокус дня
Спроектировать mobile-first paywall state, который появляется только после 3 подтверждённых действий из книги и объясняет подписку через уже видимый прогресс: книга -> действие -> повторяемый trigger -> привычка.

## Проблема
Если paywall звучит как generic AI subscription, пользователь ещё не понимает, за что платить. В book-to-habit companion ценность должна быть доказана не обещанием «AI поможет», а тем, что SiaMentor уже превратил идеи книги в три маленьких выполненных шага и нашёл рабочий жизненный слот.

## Дизайн-решение
После третьего `completed_action` показывать `Progress proof sheet` вместо обычного paywall:

1. Верхний блок: «Ты уже сделал 3 шага из книги» + короткое название книги.
2. Evidence cards: три выполненных действия с trigger и датой/днём.
3. Pattern line: «Лучше всего сработало: <trigger pattern>».
4. Friction adjustment: «На следующей неделе уменьшим трение: <friction_adjustment>».
5. Offer: «30-дневный план закрепит этот ритм» с trial/paywall CTA.

Paywall не должен открываться после чтения summary или генерации плана. Только после реального user-confirmed progress.

## Ключевые состояния
- `not_enough_actions`: меньше 3 completed actions; показываем следующий микро-шаг, paywall скрыт.
- `proof_ready`: есть 3 completed actions; показываем proof sheet перед оплатой.
- `low_confidence_memory`: если trigger/friction сомнительны, показываем только completed actions без уверенного pattern claim.
- `dismissed_paywall`: возвращаем пользователя к сегодняшнему действию, не ломаем habit streak.
- `subscribed`: следующий экран — Day 4/next action с 30-day plan context, а не receipt screen.

## UX-copy
- Заголовок: «У тебя уже есть ритм»
- Подзаголовок: «3 действия из книги превратились в повторяемый шаг. Дальше SiaMentor поможет закрепить его на 30 дней.»
- Evidence label: «Сделано»
- Pattern label: «Похоже, работает после…»
- CTA: «Продолжить 30-дневный план»
- Secondary: «Не сейчас, сделать сегодняшний шаг»
- Low-confidence fallback: «Вот что уже получилось. Следующий план продолжит с этих действий.»

## Открытые вопросы
- Считать ли 3 completed actions строго подряд или достаточно 3 за последние 7 дней?
- Нужен ли отдельный trust control «исправить» прямо на paywall, если pattern неверный?
- Какой минимум evidence нужен, чтобы не показывать ложный `best_trigger_pattern`?
- Должен ли trial CTA обещать конкретный outcome по книге или общий 30-day habit plan?
