# 2026-06-28 - Day 2 return starts from yesterday's receipt

## Фокус

Спроектировать Day 2 return screen так, чтобы пользователь возвращался не к абстрактному плану по книге, а к доказательству вчерашнего действия: книга -> сделанный шаг -> препятствие -> следующий маленький шаг.

## Проблема

После первого дня легко потерять нить: пользователь помнит "я начал книгу", но не видит, как вчерашнее действие превращается в привычку. Если Day 2 открывается пересказом книги или generic планом, продукт выглядит как LMS/AI tutor, а не consumer companion для ежедневного поведения.

Критичный риск: `plan_created` и даже `day1_completed` могут раздувать activation, если Day 2 не возвращает пользователя к конкретному receipt и не доводит до следующего действия.

## Дизайн-решение

Mobile-first экран Day 2 открывается с короткого receipt:

1. Book anchor: "Из Atomic Habits: уменьшаем трение перед стартом".
2. Yesterday receipt: "Вчера ты положил книгу на стол и прочитал 2 страницы после кофе".
3. Friction memory: "Мешало: телефон рядом".
4. Today's action: "После кофе положи телефон в другую комнату и прочитай 3 страницы. 7 минут".
5. Completion CTA: "Сделал".

Экран не предлагает чат как основной путь. AI используется для адаптации следующего действия по receipt, trigger и friction, но пользователь видит это как практический ежедневный ритуал.

## Ключевые состояния

- `d2_return_from_action_receipt`: пользователь вернулся на Day 2, видит вчерашний receipt и today's action.
- `receipt_confirmed`: receipt верный, следующий action активен.
- `receipt_corrected`: пользователь исправил trigger/friction, today's action пересобран до 5-10 минут.
- `receipt_forgotten`: memory удалена, продукт предлагает neutral fallback action из той же книги.
- `day2_action_completed`: второй completed action засчитан, progress к proof paywall становится `2/3`.

## UX-copy

- Заголовок: "Продолжим с того, что уже сработало"
- Receipt label: "Вчерашний шаг"
- Memory line: "Помню только шаг, триггер и препятствие для этой привычки."
- Correction controls: "Верно", "Исправить", "Забыть"
- Today's action: "Сегодня: 7 минут после кофе"
- CTA: "Сделал"
- Progress: "2 из 3 действий до персонального плана на 30 дней"

## Открытые вопросы

- Нужно ли показывать progress `1/3` до подтверждения receipt или только после принятия сегодняшнего действия?
- Сколько деталей из книги можно показывать в receipt без ощущения пересказа/LMS?
- Должен ли `receipt_corrected` считаться trust-positive событием для paywall proof или только privacy-control событием?
