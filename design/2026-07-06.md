# 2026-07-06 - Editable memory gate before next action

## Фокус дня
Сделать Day 2-7 вход в привычку через проверяемую память: перед новым действием пользователь видит, что SiaMentor помнит из книги и вчерашнего check-in, может исправить это, а затем сразу получает следующий микро-шаг.

## Проблема
Если приложение просто говорит "сегодня продолжим", оно выглядит как generic companion или LMS-напоминалка. Пользователь не понимает, как вчерашнее действие превратилось в сегодняшний habit design, и не доверяет paywall после 3 действий: ценность AI-памяти невидима.

## Дизайн-решение
Перед today's action показывать компактный `memory receipt gate`:

1. Книга: один тезис, выбранный пользователем.
2. Вчера: выполненное действие, trigger и friction из check-in.
3. Память: "Помню только эту привычку: ..." с действиями `Верно`, `Исправить`, `Забыть`.
4. После подтверждения или исправления сразу открывается action card на 5-10 минут.

Paywall proof после 3 completed actions должен считать только подтвержденные или исправленные receipts, а не сырую AI-инференцию.

## Ключевые состояния
- `memory_receipt_pending`: есть вчерашний check-in, next action заблокирован до выбора `Верно / Исправить / Забыть`.
- `memory_receipt_correcting`: пользователь редактирует trigger/friction одним полем, без профиля и без длинной анкеты.
- `memory_receipt_forgotten`: SiaMentor удаляет конкретную память и предлагает самый маленький безопасный next action из исходного тезиса книги.
- `next_action_from_verified_memory`: action card объясняет связь "из книги -> из вчерашнего опыта -> сегодня".
- `paywall_proof_uses_verified_receipts`: proof экран после 3 действий показывает только receipts с user-confirmed или user-corrected статусом.

## UX-copy
- Заголовок: `Проверим, что я правильно помню`
- Receipt: `Книга: "Atomic Habits" -> идея: сделать привычку очевидной.`
- Memory line: `Помню только для этой привычки: ты сделал 5 минут чтения после кофе, но помешали уведомления.`
- Buttons: `Верно`, `Исправить`, `Забыть`
- Next action: `Сегодня: после кофе положи телефон экраном вниз и прочитай 2 страницы. Отметка займет 10 секунд.`
- Correction success: `Обновил. Следующий шаг построен на исправленной версии.`

## Открытые вопросы
- Считать `Забыть` как completed trust action для paywall proof или исключать из `3/3`?
- Должна ли correction менять только следующий action или весь 7-day habit plan?
- Нужно ли показывать confidence пользователю явно, или достаточно короткого receipt и контроля?
