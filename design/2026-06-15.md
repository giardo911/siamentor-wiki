# 2026-06-15 — First session action lock

## Фокус дня

Сделать первую сессию не "планом на потом", а завершённым первым действием из книги: пользователь выбирает книгу/идею, получает микро-действие, выполняет его в интерфейсе и только после этого видит завязку привычки.

## Проблема

Если onboarding заканчивается созданным планом, цепочка книга -> действие -> привычка остаётся обещанием. Пользователь ещё не почувствовал, что продукт переводит чтение в поведение, а paywall после нескольких дней будет выглядеть как продажа AI-советов, не как продолжение доказанного прогресса.

## Дизайн-решение

Первая сессия должна иметь жёсткий core-value lock: нельзя завершить onboarding без `book_habit_day1_completed`.

Поток:

1. Книга: пользователь выбирает книгу или вводит одну идею, которую хочет применить.
2. Действие: companion предлагает один шаг до 10 минут с конкретным trigger: "после завтрака", "когда открою ноутбук", "перед сном".
3. Выполнение: пользователь отмечает, что сделал шаг, или выбирает "слишком сложно" и получает меньшую версию.
4. Привычка: интерфейс сохраняет trigger/action/friction как ограниченную habit memory и показывает завтрашний check-in.
5. Paywall: до 3 completed actions состояние `paywall_blocked`; после третьего действия можно показать proof paywall.

## Ключевые состояния

- `book_selected`: есть источник, но ещё нет действия; CTA "Выбрать первый шаг".
- `day1_action_ready`: один микро-шаг, trigger и вопрос для проверки выполнения.
- `day1_action_too_big`: пользователь снижает сложность; продукт предлагает версию <= 5 минут.
- `book_habit_day1_completed`: первый шаг сделан; сохраняем completed_action и trigger.
- `habit_seed_created`: показан завтрашний check-in и прозрачная строка памяти.
- `paywall_blocked`: подписка не показывается, пока нет 3 completed actions.

## UX-copy

- Заголовок действия: "Первый шаг из книги, сегодня"
- Trigger line: "Когда: после утреннего кофе"
- Action line: "Сделай 5-минутный список ситуаций, где применишь эту идею"
- Completion CTA: "Сделал"
- Downshift CTA: "Сделать проще"
- Memory line: "Запомню только для привычки: цель, trigger, выполненный шаг и помеху"
- Next-day bridge: "Завтра проверим, сработал ли этот trigger, и подберём следующий шаг"
- Paywall blocked copy: "Сначала соберём 3 выполненных шага, чтобы показать план на основе твоего прогресса"

## Открытые вопросы

- Считать ли typed reflection выполненным действием, если пользователь не сделал внешний physical action?
- Нужен ли режим "я уже сделал это сегодня" для пользователей, которые приходят вечером после чтения?
- Какой минимальный evidence нужен для Day 1: только completion tap или короткий текстовый proof?
- Где показывать boundary promise: до генерации действия или сразу после completion?
