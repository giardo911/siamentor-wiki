# 2026-07-18 - Forget Receipt Proof Boundary

## Фокус

`forgotten_receipt_proof_boundary`: если пользователь нажал `Забыть` на receipt действия, это действие исчезает из memory, next-action context и proof progress для paywall.

## Проблема

В цепочке книга -> действие -> привычка пользователь должен контролировать, какие выполненные действия становятся доказательством прогресса. Если SiaMentor продолжит считать забытый receipt в `3/3` proof gate, paywall будет выглядеть как монетизация данных, которые пользователь явно убрал.

## Дизайн-решение

После `Забыть` показываем короткое подтверждение: действие удалено из памяти этой привычки, proof progress пересчитан, следующий шаг будет построен только из оставшихся verified/corrected receipts и текущей идеи книги. Пользователь не попадает в generic chat и не теряет loop: получает новый микро-шаг <=5 минут, но без ссылки на забытое действие.

## Ключевые состояния

- `receipt_forget_confirmed`: receipt скрыт, событие `habit_memory_deleted_by_user`, copy объясняет, что удалено именно из памяти привычки.
- `proof_progress_after_forget`: progress пересчитан, например `2/3 проверенных действий`; proof paywall не появляется до нового verified/corrected receipt.
- `next_action_after_forget`: action <=5 минут, основан на книге, goal и последнем оставшемся verified receipt; запрещены ссылки на forgotten trigger/friction/action.
- `proof_gate_blocked_by_forget`: если до удаления было `3/3`, paywall заменяется на free action для восстановления доказательства.

## UX-copy

- Заголовок: `Действие забыто`
- Receipt line: `Я больше не использую это действие для следующих шагов и доказательства прогресса.`
- Progress: `Осталось: 2/3 проверенных действий до 30-дневного продолжения.`
- Free action CTA: `Сделать новый шаг на 5 минут`
- Boundary copy: `Память SiaMentor ограничена этой привычкой: книга, цель, trigger, действие и препятствие.`

## Открытые вопросы

- Нужно ли показывать undo в течение одной сессии, или `Забыть` должен быть необратимым для доверия?
- Считать ли forgotten receipt в анонимной aggregate-аналитике качества habit design, если пользователь удалил его из персональной памяти?
- Как объяснить падение `3/3 -> 2/3` без ощущения наказания за privacy action?
