# 2026-06-11 — Memory trust перед следующим действием

## Фокус

Day 2–7 check-in: перед новым микро-действием SiaMentor показывает, что он помнит из прошлого выполненного действия, и даёт быстрый контроль `верно / исправить / забыть`.

## Проблема

Book-to-habit companion должен вести цепочку `книга -> действие -> привычка`, но персонализация становится рискованной, если пользователь не понимает, на какой памяти основан следующий шаг. Без прозрачности следующий action может выглядеть как generic self-help совет или как навязчивая "AI-память".

## Дизайн-решение

На экране Day 2–7 check-in первым блоком показывать короткую строку памяти:

> Помню со вчера: после кофе ты сделал 5-минутный разбор одной рабочей встречи.

Под строкой — три compact action:

- `Верно` — подтверждает evidence и открывает today's action.
- `Исправить` — открывает короткий inline edit: trigger, completed action, friction.
- `Забыть` — удаляет этот fact из habit memory и продолжает с неперсонализированным next action.

После подтверждения SiaMentor связывает книгу с действием:

> Из "Atomic Habits": повторяем тот же trigger, но уменьшаем шаг до 3 минут, если утро перегружено.

Главная логика: пользователь сначала проверяет память, потом получает следующий if-then шаг. Это делает персонализацию видимой и контролируемой.

## Ключевые состояния

- `memory_confirmed`: показываем next action, основанный на confirmed trigger.
- `memory_correcting`: inline форма с тремя полями и CTA `Сохранить и продолжить`.
- `memory_forgotten`: neutral state `Ок, не буду использовать это в следующих шагах` + fallback action из `goal + book_slug`.
- `memory_stale`: если последний check-in старше N дней, вместо уверенной памяти показываем grace restart flow.
- `unsupported_memory`: если fact вне habit allowlist, не показываем его и логируем eval failure.

## UX-copy

- Header: `Сначала проверим, что я правильно помню`
- Memory line: `Помню со вчера: {trigger} -> {completed_action}`
- Confirm CTA: `Верно`
- Correction CTA: `Исправить`
- Forget CTA: `Забыть`
- Next action intro: `Тогда сегодняшний шаг:`
- Fallback copy: `Продолжим без этой памяти. Я возьму только книгу и твою цель.`

## Открытые вопросы

- Нужно ли требовать явное `Верно` каждый день или только когда memory используется для изменения next action?
- Где хранить correction reason: отдельным `habit_memory_corrected` event или как поле в corrected fact?
- Показывать ли `source_checkin_id` пользователю явно или оставить только evidence snippet?
- Сколько correction friction допустимо до падения Day 2 completion?
