- Источник: https://www.datarefs.com/statistics/ai/ai-in-education/
- Дата: published last week, crawled today.
- Что значит для SiaMentor: рынок привыкает к AI help, но "AI отвечает за меня" не равно progress. Book-to-habit должен держать activation на completed action, а не на plan_created или minutes spent.

### 3. Memory systems остаются privacy/security risk
- Источник: https://www.nextmoca.com/blog/weekly-ai-wrap-july-13-19-2026/
- Дата: July 20, 2026.
- Что значит для SiaMentor: agent memory может быть attack surface и trust risk. Поэтому habit memory должна быть bounded: только last receipt, trigger, action, friction и user corrections.
