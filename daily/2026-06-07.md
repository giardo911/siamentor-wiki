## Топ-материалы

### 1. OpenAI: Dreaming — better memory for ChatGPT
- **Источник:** OpenAI, 2026-06-04: https://openai.com/index/chatgpt-memory-dreaming/
- **Evidence:** OpenAI описывает memory synthesis как способ держать memories более актуальными, полезными и масштабируемыми; отдельный акцент — обновлять устаревший контекст, а не слепо тащить прошлые факты.
- **Inference для SiaMentor:** next habit action должен ссылаться только на свежие подтвержденные facts или явно low-confidence inference.
- **Практический вывод:** Добавить before-action memory card: `Помню из прошлого check-in: <evidence_snippet>` + кнопки `верно`, `исправить`, `забыть`.

### 2. OpenAI Memory FAQ
- **Источник:** OpenAI Help Center, crawled 2026-06-06: https://help.openai.com/en/articles/8590148-memory-faq
- **Evidence:** Memory product expectation включает пользовательский контроль: посмотреть, обновить, удалить, отключить memory.
- **Inference для SiaMentor:** Даже если memory маленькая и доменная, пользователю нужен явный контроль над тем, что companion помнит.
- **Практический вывод:** В MVP не хранить скрытый "профиль личности"; хранить habit facts с `source_checkin_id` и UI-коррекцией.

### 3. Public reaction: memory backlash and control anxiety
- **Источник:** Reddit/OpenAI discussion, 2026-06-04/05: https://www.reddit.com/r/OpenAI/comments/1tx2std/how_to_avoid_chatgpts_damaging_upgrade_to_saved/
- **Evidence:** Часть power users воспринимает memory rewrite как потерю точности и контроля, особенно когда summary становится более общим.
- **Inference для SiaMentor:** Синтезированная memory не должна заменять evidence. Для habit coaching опасно превращать конкретное "после кофе сделал 5 минут" в расплывчатое "любит продуктивность".
- **Практический вывод:** Разделить append-only check-in events и derived facts; показывать source snippet рядом с derived fact.

### 4. Consumer question: what makes an AI companion a real product?
- **Источник:** Reddit/ChatGPT, 2026-06-02: https://www.reddit.com/r/ChatGPT/comments/1tud5mm/what_would_make_an_ai_companion_meaningly/
- **Evidence:** В обсуждениях recurring темы: long-term memory, continuity, полезное отличие от "ChatGPT with friendlier tone".
- **Inference для SiaMentor:** Differentiation должна быть в поведенческом loop, а не в persona. Пользователь возвращается, если вчерашний trigger влияет на сегодняшнее действие.
- **Практический вывод:** Мерить `same_trigger_completed_days / active_days` и показывать пользователю pattern: "утро после кофе работает лучше, чем вечер".

### 5. Learning companions: agency over task performance
- **Источник:** arXiv 2605.04816, 2026-05-06: https://arxiv.org/abs/2605.04816
- **Evidence:** Исследование learning companions подчеркивает learner agency, transparency и durable learning вместо краткосрочной task performance.
- **Inference для SiaMentor:** Book-to-habit продукт должен просить выбор trigger/confidence и check-in факт, а не просто выдавать советы.
- **Практический вывод:** Day 1-3 actions должны быть ≤10 минут, с одним trigger, if-then формулировкой и check-in вопросом, который обновляет следующий action.
