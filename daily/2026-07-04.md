### 1. Mem0: continual learning agent через structured outcomes
- **Источник:** How to Build a Continual Learning Agent with Mem0, 2026-07-02: https://mem0.ai/blog/how-to-build-a-continual-learning-agent-with-mem0
- **Evidence:** материал описывает агента, который после задачи сохраняет структурированный outcome, достает релевантные прошлые outcomes перед похожей задачей и уточняет стратегию.
- **Inference для SiaMentor:** memory должна быть не "помню все о тебе", а журналом проверяемых habit outcomes: что сделал, какой trigger сработал, где friction, какой next adjustment.

### 2. Springer / AIED: learning with an AI agent tutor
