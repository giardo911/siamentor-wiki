## Свежие источники

### 1. Persistent memory poisoning
- Источник: https://www.forcepoint.com/blog/x-labs/persistent-memory-poisoning-ai-agents
- Дата: 2026-08-04.
- Что значит для SiaMentor: agent memory — память агента между сессиями — должна быть inspectable object, а не скрытая "истина". Для book-to-habit это поддерживает typed receipt, source evidence и correction controls перед следующими действиями/paywall.

### 2. Memory poisoning в медиа-срезе
- Источник: https://www.itpro.com/security/trust-your-ai-agents-new-research-shows-memory-poisoning-can-dupe-them-into-remembering-fake-information-and-its-a-huge-security-risk
- Дата: 2026-08-11.
- Что значит для SiaMentor: риск не только в prompt injection внутри одной сессии, а в долгоживущей ложной памяти. Значит, retention loop должен строиться вокруг проверяемых check-in receipts, а не вокруг невидимого профиля пользователя.

### 3. AI apps retention gap
- Источник: https://techcrunch.com/2026/03/10/ai-powered-apps-struggle-with-long-term-retention-new-report-shows/
- Дата: 2026-03-10.
- Что значит для SiaMentor: consumer AI подписки страдают от удержания, поэтому paywall должен показывать наблюдаемый прогресс и daily action loop. Сегодняшний eval снижает риск answer-machine поведения: пользователь должен уйти не с советом, а с действием и check-in.

## Решение дня
Закрывать motivation gap через product contract, а не только через copy: любой "совет из книги" должен сворачиваться в одно сегодняшнее действие, trigger и вопрос для check-in.
