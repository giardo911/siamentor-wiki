## Свежие источники

### 1. Memory poisoning / inspectable memory
- Источник: https://www.itpro.com/security/trust-your-ai-agents-new-research-shows-memory-poisoning-can-dupe-them-into-remembering-fake-information-and-its-a-huge-security-risk
- Дата: 2026-08-11.
- Что значит для SiaMentor: agent memory — сохраненная память агента между сессиями — нельзя считать автоматически истинной. Для book-to-habit это подтверждает typed receipts, source-bound evidence и пользовательские correction controls: память должна быть проверяемым объектом, а не скрытым профилем.

### 2. Memory governance / user review
- Источник: https://www.techradar.com/pro/security/experts-find-ai-agents-can-be-tricked-into-remembering-fake-facts-for-months-so-how-do-we-stop-it
- Дата: 2026-08-10.
- Что значит для SiaMentor: persistent memory может отравляться обычными пользовательскими или web-вводами и влиять на будущие действия. Значит, SiaMentor стоит продолжать показывать evidence snippets и `исправить / забыть`, особенно перед paywall, где trust напрямую влияет на оплату.

### 3. Subscription fatigue / underuse risk
- Источник: https://nypost.com/2026/08/12/lifestyle/heres-what-consumers-are-canceling-in-2026/
- Дата: 2026-08-13.
- Что значит для SiaMentor: пользователи режут подписки, которые ощущаются недоиспользованными. Поэтому paid offer должен продавать не "доступ к AI", а наблюдаемый прогресс: completed actions, streak, D1/D7 retention и понятный следующий шаг на сегодня.
