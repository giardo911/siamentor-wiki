## Топ-материалы

### 1. BBB National Programs: emerging regulatory framework for AI chatbots
- **Источник:** BBB National Programs / Center for Industry Self-Regulation, июнь 2026: https://industryselfregulation.org/media-resource/media/blog/ai-chatbot-regulations
- **Evidence:** chatbot regulation двигается к clear disclosures, privacy limits и особой осторожности вокруг minors/targeted advertising.
- **Inference для SiaMentor:** даже взрослый D2C product лучше позиционировать как bounded habit utility: пользователь должен видеть, что AI помнит только данные привычки и использует их для следующего действия.
- **Практический вывод:** добавить copy regression check `bounded_companion_language`: запрещать claims типа "глубоко понимаю тебя" без явной utility boundary.

### 2. TrustArc: AI and children's privacy 2026 regulatory guide
- **Источник:** TrustArc, май 2026: https://trustarc.com/resource/ai-childrens-data-2026/
- **Evidence:** privacy/regulatory pressure вокруг AI усиливается через EU AI Act, COPPA и state design codes; ключевой вопрос — насколько быстро стратегия продукта успевает за требованиями.
- **Inference для SiaMentor:** если продукт остается adult D2C, это не отменяет privacy expectations: memory receipt должен быть editable/deletable, а broad profiling — вне scope.
- **Практический вывод:** privacy copy рядом с receipt: "помню только действия из этой привычки" + `Верно / Исправить / Забыть`.

### 3. RevenueCat: State of Subscription Apps 2026
- **Источник:** RevenueCat, 2026: https://www.revenuecat.com/state-of-subscription-apps/
- **Evidence:** retention у AI apps ниже across weekly/monthly/annual subscription durations; пример benchmark: monthly AI 6.1% vs non-AI 9.5% after 12 months.
- **Inference для SiaMentor:** proof paywall after 3 actions нельзя оптимизировать только под trial start; нужно доказывать recurring value и измерять продолжение привычки после paywall.
- **Практический вывод:** dashboard должен включать `habit_paywall_proof_rendered -> free_continue_clicked -> free_action_completed_after_paywall -> d7_retained -> trial_started`.

### 4. RevenueCat: sustainable AI subscription pricing model
- **Источник:** RevenueCat Growth, 2026: https://www.revenuecat.com/blog/growth/ai-subscription-app-pricing/
- **Evidence:** AI apps несут variable compute cost per interaction; growth должен учитывать GPU burn, а не только CAC и conversion.
- **Inference для SiaMentor:** бесплатный 7-day loop должен быть cheap-by-design: bounded prompts, короткие микро-действия, structured memory, минимум open-ended chat.
- **Практический вывод:** добавить cost guardrail на habit loop: LLM calls per completed action и fallback template для Day 2-7 action, если verified memory достаточно структурирована.

### 5. Mem0: personalized AI tutor memory pattern
- **Источник:** Mem0 docs, AI Tutor cookbook: https://docs.mem0.ai/cookbooks/companions/ai-tutor
- **Evidence:** AI tutor memory pattern хранит progress/preferences across sessions для context-aware tutoring.
- **Inference для SiaMentor:** полезная memory — это не "персональность пользователя", а state для поведения: book thesis, trigger, completed action, friction, next adjustment.
- **Практический вывод:** после verified receipt нужен test на shrink/reanchor: если friction повторяется два дня, next action должен стать <=5 минут и получить новый if-then trigger.
