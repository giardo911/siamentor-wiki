## Топ-материалы

### 1. AgentSchool: learning agent надо оценивать как state transition
- **Источник:** arXiv, 2026-05-28: AgentSchool: An LLM-Powered Multi-Agent Simulation for Education — https://arxiv.org/abs/2605.30144
- **Evidence:** Работа моделирует обучение как переход состояния, а не как persona role-play; student agents имеют knowledge graphs, workflows и explicit misconceptions, teacher agents планируют/scaffold/reflect.
- **Inference для SiaMentor:** Book-to-habit companion тоже должен хранить state transition: `goal -> trigger -> action_done/action_missed -> friction -> next_micro_action`.
- **Практический вывод:** Не начинать с "умного чата по книге". Начать с typed plan state и check-in state, которые меняются каждый день.

### 2. TaskMem: memory должна быть task-focused, а не просто long-term storage
- **Источник:** Hugging Face Papers, 2026-05-29: Task-Focused Memorization for Multimodal Agents — https://huggingface.co/papers/2605.31075
- **Evidence:** Описание работы подчёркивает динамическое решение, какую информацию сохранять в long-term memory для выполнения задачи, с приростом качества на streaming benchmarks.
- **Inference для SiaMentor:** После check-in не надо сохранять весь разговор. Надо сохранять только то, что меняет завтрашнее действие: completed action, friction, confidence, trigger viability.
- **Практический вывод:** В Phase 8 добавить memory write rubric: "будет ли этот факт полезен для выбора Day N+1 action?"

### 3. RevenueCat retention: отменивших annual subscribers почти невозможно вернуть
- **Источник:** 9to5Mac, 2026-05-27, summary of RevenueCat State of Subscription Apps 2026 Part 2 — https://9to5mac.com/2026/05/27/new-report-shows-annual-app-subscribers-rarely-return-after-they-cancel/
- **Evidence:** В статье говорится, что annual reactivation около 5%, а большая часть trial cancellations случается очень рано.
- **Inference для SiaMentor:** Paywall после 3 completed actions правильнее, чем paywall до value moment, но сам paywall должен показывать конкретный progress artifact.
- **Практический вывод:** Экран paywall: "ты уже внедрил 3 действия из книги: X, Y, Z; 30-дневный план закрепит это" + waitlist/email or payment test.

### 4. RevenueCat AI apps: AI hype не равен retention
- **Источник:** RevenueCat State of Subscription Apps 2026, shopping/productivity pages — https://www.revenuecat.com/state-of-subscription-apps-2026-shopping/ и https://www.revenuecat.com/state-of-subscription-apps-2026-productivity/
- **Evidence:** RevenueCat пишет, что AI-приложения показывают слабее long-term retention; в одном из срезов AI retains 2.5% weekly, 6.1% monthly, 21.1% annually at 12 months против более высоких non-AI показателей.
- **Inference для SiaMentor:** "AI companion" как label не является moat. Moat — повторяемый daily value loop и доказательство, что пользователь меняет поведение.
- **Практический вывод:** В аналитике Phase 8 надо смотреть не только `habit_plan_created`, а completion chain: Day1 completed, D1 return, Day3 completed, paywall view after 3 actions, D7 retention.
