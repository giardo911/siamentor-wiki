## Свежие источники

### 1. Persistent memory poisoning снова в повестке
- Источник: https://www.techradar.com/pro/security/experts-find-ai-agents-can-be-tricked-into-remembering-fake-facts-for-months-so-how-do-we-stop-it
- Дата: 2026-08-10.
- Что значит для SiaMentor: agent memory — память агента между сессиями — должна оставаться проверяемым receipt, а не скрытым профилем. Для book-to-habit это подтверждает текущую линию: показывать source evidence, trigger и correction controls перед следующим действием/paywall.

### 2. Forcepoint: память агента как долговременная attack surface
- Источник: https://www.forcepoint.com/blog/x-labs/persistent-memory-poisoning-ai-agents
- Дата: 2026-08-04.
- Что значит для SiaMentor: долговременная память может silently менять будущие рекомендации. Поэтому сегодняшняя метрика trigger consistency важна не только для retention, но и для trust: мы оптимизируем повторяемый пользовательский trigger из check-in receipts, а не произвольную персонализацию.
