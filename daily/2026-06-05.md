## Топ-материалы

### 1. OpenAI: Dreaming — better memory for ChatGPT
- **Источник:** OpenAI, 2026-06-04: https://openai.com/index/chatgpt-memory-dreaming/
- **Evidence:** OpenAI описывает новую систему синтеза memory для ChatGPT, нацеленную на freshness, continuity, relevance, correctness и scalability на многолетних горизонтах.
- **Inference для SiaMentor:** У habit companion есть такая же проблема, только в узком домене: память должна обновляться во сне/после check-in, но следующий action обязан опираться на свежие и проверяемые факты.
- **Практический вывод:** Добавить `memory_last_synthesized_at`, `source_checkin_id`, `evidence_snippet` и stale-memory fallback: если memory устарела или low-confidence, следующий action генерируется из текущего goal + trigger, без притворной персонализации.

### 2. RevenueCat State of Subscription Apps 2026
- **Источник:** RevenueCat, crawled last week: https://www.revenuecat.com/state-of-subscription-apps/
- **Evidence:** В бенчмарке AI apps имеют retention ниже non-AI на weekly/monthly/annual durations, при этом AI сохраняет RLTV premium.
- **Inference для SiaMentor:** Пользователь может заплатить за AI, но останется только если увидит повторяемую пользу в поведении.
- **Практический вывод:** Paywall должен показывать "ты уже сделал 3 действия" + next 30-day promise; метрика не только `habit_paywall_clicked`, но и `paywall_proof_rendered`.

### 3. AI retention field note: habit formation over raw DAU
- **Источник:** TLDL, 2026-02-17, crawled today: https://www.tldl.io/blog/ai-retention-habit-formation
- **Evidence:** Автор утверждает, что главный вопрос retention для AI-продукта — появляется ли у пользователя повторяемый слот в жизни, а не просто возвращается ли он в продукт.
- **Inference для SiaMentor:** NSM `daily_habit_checkins_completed` хорош, но его надо читать вместе с trigger consistency: пользователь возвращается в тот же контекст или хаотично открывает чат.
- **Практический вывод:** В check-in добавить поле `trigger_matched` и дашборд `same_trigger_completed_days / active_days`.

### 4. Building AI Companions that Prioritise Learning over Performance
- **Источник:** arXiv 2605.04816, 2026-05-06: https://arxiv.org/abs/2605.04816
- **Evidence:** Paper предлагает проектировать AI learning companions вокруг learning, adaptation, transparency, accountability и learner agency, а не только task performance.
- **Inference для SiaMentor:** Даже если старый EdTech wedge не primary, book-to-habit продукт выигрывает от agency: пользователь должен выбирать trigger и подтверждать action, а не пассивно получать "мудрый совет".
- **Практический вывод:** В Day 1–3 flow сохранить user choice: выбрать trigger, оценить confidence, отметить friction; AI предлагает next action, но не забирает контроль.

### 5. Companion memory market reviews as weak consumer signal
- **Источник:** CompanionWise, updated 2026-04-09: https://companionwise.com/best/ai-companion-with-memory/
- **Evidence:** Consumer reviews ранжируют companion apps по качеству memory и явно выделяют различие между "помнит внутри сессии" и "помнит между сессиями".
- **Inference для SiaMentor:** Для D2C пользователя memory — не backend feature, а ощутимое обещание: "он помнит, что сработало/не сработало вчера".
- **Практический вывод:** В daily check-in UI показать короткую строку remembered context: "Вчера сработал триггер X; сегодня уменьшаем действие до Y".

- **Evidence:** Свежий OpenAI memory release прямо называет freshness/correctness/scalability проблемами long-term memory.
