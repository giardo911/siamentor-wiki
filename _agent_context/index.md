# SiaMentor Agent Context

OpenWiki-style overlay for agent work on SiaMentor.

This folder is the current compact context layer. It does not replace `daily/`, `design/`, `strategy/`, or `project-checklist.md`; it summarizes the current product truth so agents do not reconstruct it from long historical logs on every task.

## Read order

1. [[current-state]] - current wedge, live product loop, next bottleneck.
2. [[metrics]] - event taxonomy and CEO dashboard chain.
3. [[backlog]] - active priorities and explicit non-goals.
4. [[decisions]] - durable decisions that should constrain new work.
5. [[sources]] - authority levels and refresh rules.

## Working rule

For implementation tasks, use this folder as the starting context, then open the linked source files only when the task needs detail or evidence. Treat `daily/` and `design/` as raw logs, not as the main retrieval layer.
