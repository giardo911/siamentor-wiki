## Summary

Зафиксированы 3 стартовые книги для MVP с обоснованием выбора по критериям: узнаваемость в русскоязычной аудитории, поисковый спрос, разнообразие ICP, наличие конкретных привычек для внедрения. Спроектирован onboarding-флоу «книга→цель→Day 1» без upload за ≤2 минуты. Каждая книга имеет предзаданный 7-дневный план (Day 1–7) в формате implementation intentions (if-then), который генерируется мгновенно при выборе без вызова LLM на каждый запрос. Активационное событие: `book_habit_day1_completed` фиксируется после выполнения и check-in первого задания.

### 3 стартовые книги MVP

#### Критерии отбора
1. Высокая узнаваемость (читатели знают книгу без объяснений)
2. Чёткие, конкретные habits/actions — легко превратить в if-then задания
3. Разные ICP — покрываем три разных мотивации пользователя
4. Органический спрос: запросы «[книга] план», «[книга] внедрить», «[книга] summary действия»

---

#### Книга 1: Atomic Habits (James Clear) / «Атомные привычки»

**Почему выбрана:**
- Самая популярная книга о привычках в мире, переведена на русский, огромный органический спрос
- Чёткая система: cue → craving → response → reward + 4 закона формирования привычек
- ICP: пользователь хочет внедрить любую привычку (утренняя зарядка, чтение, медитация)
- Самый широкий охват — подходит почти всем

**Ключевые темы для 7-дневного плана:**
- День 1: habit stacking (привязать новую привычку к существующей)
- День 2: environment design (изменить окружение под новую привычку)
- День 3: 2-minute rule (начать с версии привычки на 2 минуты)
- День 4: identity-based habit («Я человек, который…»)
- День 5: tracking (не нарушать цепочку)
- День 6: temptation bundling (связать неприятное с приятным)
- День 7: review + планирование следующей недели

**Пример Day 1 (if-then):**
> «Если я [утром после кофе / вечером перед сном / в определённое время], то я [выбранная микро-привычка] в течение 2 минут.»

---

#### Книга 2: «7 навыков высокоэффективных людей» (Stephen Covey)

**Почему выбрана:**
- Классика бизнес-литературы, один из самых продаваемых non-fiction в мире
- ICP: пользователь хочет стать более продуктивным / организованным / эффективным
- Высокий WTP: бизнес-аудитория, готова платить за конкретные результаты
- Навыки конкретны и хорошо ложатся в ежедневные микро-действия

**Ключевые темы для 7-дневного плана:**
- День 1: Навык 1 — Проактивность (выписать 3 вещи вне твоего контроля и 3 внутри)
- День 2: Навык 2 — Начинать с конца (написать личную миссию в 1 предложении)
- День 3: Навык 3 — Первые вещи первыми (матрица Эйзенхауэра на завтра)
- День 4: Навык 4 — Думать «выиграл/выиграл» (найти взаимовыгодное решение в одной ситуации)
- День 5: Навык 5 — Сначала понять, потом быть понятым (активное слушание в 1 разговоре)
- День 6: Навык 6 — Синергия (найти человека с дополняющими навыками)
- День 7: Навык 7 — Затачивать пилу (выбрать 1 из 4 сфер: тело/разум/душа/социум)

**Пример Day 1 (if-then):**
> «Если сегодня я столкнусь с проблемой, то сначала спрошу себя: "Это в моём круге влияния?" — и запишу ответ.»

---

#### Книга 3: «4-часовая рабочая неделя» (Tim Ferriss)

**Почему выбрана:**
- Культовая книга среди entrepreneurs, freelancers, remote workers
- ICP: пользователь хочет высвободить время / автоматизировать рутину / делегировать
- Самые конкретные, измеримые задания из трёх книг — легко верифицировать выполнение
- Уникальный ICP, не пересекается с двумя другими книгами

**Ключевые темы для 7-дневного плана:**
- День 1: Dreamlining (написать 5 целей на 6 месяцев с конкретными числами)
- День 2: Fear-setting (Stoic exercise: worst case / probability / fix)
- День 3: 80/20 analysis (найти 20% задач, дающих 80% результата)
- День 4: Low-information diet (отключить 1 источник новостей/соцсетей на день)
- День 5: Batching (объединить все email/звонки в 1 временной блок)
- День 6: Time audit (записывать каждые 30 минут что делаешь — 1 день)
- День 7: Outsource experiment (делегировать 1 задачу или автоматизировать 1 рутину)

**Пример Day 1 (if-then):**
> «Если я сяду за компьютер сегодня, то первые 10 минут потрачу на запись 5 конкретных целей с числами (не "стать богатым", а "зарабатывать 150 000 ₽/мес к ноябрю 2026").»

### Онбординг-флоу «книга→цель→Day 1» (≤2 минуты)

**Принцип:** нет upload, нет ожидания — пользователь видит Day 1 за 4 шага.

#### Шаг 1 — Выбор книги (экран 1)
```
Какую книгу хочешь внедрить?

[ Atomic Habits ]       [ 7 навыков ]       [ 4-часовая рабочая неделя ]

    Формирование           Продуктивность        Освобождение времени
    любой привычки         и эффективность       и автоматизация
```
- Одна кнопка, без скролла
- Под каждой книгой — 5-слов описание результата (не название темы)

#### Шаг 2 — Цель пользователя (экран 2)
```
Что именно хочешь изменить?

[____________________________________________]
Например: «хочу вставать в 6 утра»
          «хочу читать 20 минут каждый день»
          «хочу перестать откладывать задачи»

[ Продолжить → ]
```
- Free text, 1 строка
- Placeholder — конкретные примеры, не абстракции
- Цель сохраняется в habit memory и персонализирует план

#### Шаг 3 — Выбор триггера (экран 3)
```
Когда будешь выполнять задание?

[ Утром, после пробуждения ]
[ После конкретного события: ___________ ]
[ Вечером, перед сном ]

[ Продолжить → ]
```
- Триггер встраивается в if-then формулировку Day 1
- «После конкретного события» — поле ввода (утреннего кофе / обеда / рабочего звонка)

#### Шаг 4 — Day 1 (экран 4, activation screen)
```
День 1 из 7 · Atomic Habits

Твоя цель: «хочу читать 20 минут каждый день»

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Сегодняшнее задание:

«Если я выпью утренний кофе,
то сразу открою книгу на 2 минуты —
не 20, а просто 2 минуты.»
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ ✓ Выполнил — отметить check-in ]    [ Напомни вечером ]
```
- Задание уже сформулировано в if-then с триггером пользователя
- Кнопка check-in → `book_habit_day1_completed` → activation event → streak начинается

### Технические решения для быстрого старта

**Контент-стратегия: pre-generated plans, не LLM on-demand**

Для MVP каждая книга имеет **фиксированный 7-дневный план** (7 заданий), хранящийся статически. LLM используется только для:
- Персонализации if-then формулировки под триггер и цель пользователя
- Ответов на вопросы пользователя в рефлексии

Это снижает latency (Day 1 показывается мгновенно) и стоимость (1 LLM call на онбординг, не 7).

**Data model (минимальная для MVP):**
```typescript
interface UserHabitPlan {
  userId: string
  bookId: "atomic-habits" | "7-habits" | "4hww"
  goal: string                    // цель пользователя
  trigger: string                 // выбранный триггер
  currentDay: number              // 1–7
  streak: number
  graceDay: boolean               // использован ли grace day в этом цикле
  lastCheckIn: Date | null
  completedDays: number[]         // [1, 2, 3, ...]
}
```

**Activation event trigger:**
- `book_habit_day1_completed` = currentDay становится 1 + checkIn записан
- Фиксируется в PostHog (уже подключён): `posthog.capture('book_habit_day1_completed', { bookId, goal })`
